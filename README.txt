SHERWIN CASANOVA PORTFOLIO — QUICK START

1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.
4. Replace placeholder text (email, social links, school names, dates) with your real information.
5. Put your own images in assets/images using these filenames:
   profile.jpg, about.jpg, about-place.jpg, act-1.jpg, act-2.jpg, act-4.jpg,
   act-5.jpg, act-6.jpg, immersion-logo.png, shopee-logo.png, college-logo.png,
   certificate-1.jpg, certificate-2.jpg, cv-preview.jpg, cv.pdf
   Image placeholders will appear if a file is missing.
6. Project detail pages are inside the projects folder. Edit the title, description,
   tools, process, and image placeholders for each ACT.
7. Contact form is front-end only. To receive messages, connect a form/email service
   or build a backend.
8. For hosting, publish the whole folder to GitHub Pages, Netlify, or another static host.

FILES
- index.html: one-page scrolling portfolio
- style.css: colors, responsive layout, components
- script.js: mobile navigation, dark mode, project filters/search, contact form notice
- projects/act-1.html ... act-6.html: separate project detail pages

NOTE: This is a starter template. Verify all personal information, links, images, CV,
and contact form behavior before sharing publicly.
